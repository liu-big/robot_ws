# 大疆 RoboMaster C620 + M3508

手册: `~/robot_ws/RoboMaster C620无刷电机调速器使用说明（中英日）V1.01.pdf`

## 接线

| 项目 | 说明 |
|------|------|
| CAN 总线 | **can2**（本机，原 can1 硬件坏） |
| 波特率 | **1 Mbps** |
| 帧类型 | **标准帧 11-bit**（非扩展帧） |
| 电源 | 24V（XT30） |
| 终端电阻 | C620 板上开关 + 总线两端 120Ω |

## 电调 ID 设置

- 支持 ID：**1 ~ 8**
- 单独设置：按 SET 键，按 N 次 = ID N
- 快速设置：长按 SET 至全绿灯，依次转动各 M3508 转子 ≥180°

**同一 CAN 总线上 ID 不能重复。**

## CAN 协议摘要

### 主机 → 电调（电流控制）

| CAN ID | 控制电机 |
|--------|----------|
| `0x200` | ID 1~4（各 2 字节 int16） |
| `0x1FF` | ID 5~8（各 2 字节 int16） |

- 电流值范围：**-16384 ~ 16384** → 对应 **-20A ~ +20A**
- DATA[0:1] = 电机1, DATA[2:3] = 电机2, ...

### 电调 → 主机（反馈）

| CAN ID | 说明 |
|--------|------|
| `0x200 + motor_id` | ID1 → `0x201`, ID2 → `0x202` ... |

反馈含：转子位置、转速、温度等（见手册 Data Fields 表）。

## Linux 测试

```bash
~/robot_ws/scripts/can-hub-up.sh

# 监听 C620 反馈（ID=1 时 0x201）
candump -tz can2,201:7FF

# 发送零电流保活（0x200 帧，4 路全 0）
cansend can2 200#0000000000000000
```

## 与灵足 RS03 的区别

| | can0 灵足 RS03 | can1 大疆 C620 |
|--|----------------|----------------|
| 帧格式 | **扩展 29-bit** | **标准 11-bit** |
| 波特率 | 1 Mbps | 1 Mbps |
| 控制方式 | RobStride 运控（可锁角） | **CAN 只发电流**（无位置伺服） |
| 使能站立 | 固件位置保持 | 主机速度环；**不能当腿关节锁位** |

C620 手册与 RoboMaster 开源实现均表明：位置/速度环须在主控（通常 STM32 **1kHz**）上算 PID，电调只执行电流。  
麦轮走路用 **速度闭环**；停转发 0 电流即卸力，不要指望像灵足一样锁角。

两路 CAN **必须分开**，不能混在同一 SocketCAN 接口。
